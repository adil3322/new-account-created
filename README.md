# new-account-created Website

A simple and responsive Sign-In and User Profile web application built using HTML, CSS, JavaScript, Node.js, and MongoDB.

## Features

- User Sign-In / Login
- User Profile
- Responsive Design
- Backend API using Node.js and Express
- MongoDB database integration
- Secure environment variables using `.env`

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Node.js
- Express.js
- MongoDB
